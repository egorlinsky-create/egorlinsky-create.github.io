# Концепт Command

Самостоятельная копия Astro-проекта из Sites, версия №19.

- Источник: https://gorlinsky-command-concept.e-gorlinsky.chatgpt.site/command
- Исходный коммит Sites: `935fc4ae68f94b89566afb8ad0f0567cb07429de`.
- Сохранены исходники, страницы кейсов, прототипы и все публичные ассеты, включая варианты портрета.
- Bebas Neue Cyrillic, Onest и JetBrains Mono находятся в `public/fonts/` вместе с лицензиями. Подключение Google Fonts заменено локальным CSS.
- Служебные настройки Sites, CI и копии навыков агентов не переносились.

## Запуск

Из `concept/command/`:

```sh
npm ci
npm run dev
```

Открой `http://localhost:4321/command`. Сборка: `npm run build`; результат — `dist/`.

Папка — отдельный проект. Добавление в репозиторий само по себе не публикует концепт по пути `/concept/command/` на GitHub Pages.
