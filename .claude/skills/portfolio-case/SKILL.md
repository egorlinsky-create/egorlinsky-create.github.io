# Кейс портфолио

Кейс отвечает рекрутеру и дизайн-лиду на три вопроса: **как ты думаешь, что ты сделал сам, к чему это привело.** Всё, что не помогает ответить, — убрать.

## Порядок работы

1. **Собери исходник.** Notion-страница кейса, отчёты, макеты. Цифры берёшь только отсюда.
2. **Сформулируй JTBD кейса** одной фразой для себя (в текст не идёт): кто пользователь, какая работа, какой барьер.
3. **Заполни frontmatter** (это и есть карточка на главной) — схема ниже.
4. **Напиши тело** по скелету. Заголовок секции = вывод, а не тема: «Метка риска не заменяет обращение», а не «Исследование».
5. **Вставь доказательства:** картинка или прототип на каждый ключевой тезис.
6. **Прогони чеклист** внизу.

## Frontmatter

```yaml
---
title: "Подборка финдиректоров под клиента: решение о договоре за 2 дня вместо месяца"
cardTitle: "Подборка финдиректоров"    # короткое имя для карточки, ≤ 32 символов
summary: "Время до решения о договоре: с месяца до 2 дней"  # итог, ≤ 90 символов
company: "Нескучные финансы"
product: "ERP · панель распределения клиентов"
type: "Продукт"            # Продукт | Система | Исследование
status: "В продакшене"     # В продакшене | Работает и развивается | Используется в ERP | Изменило постановку задачи
order: 0                   # порядок на главной
cover: "/images/selection/card.jpg"   # 16:10, ≥ 1600px по ширине
accent: "green"            # green | blue | purple | gray — цвет статуса
---
```

`Outcome.status`: `done` (в продукте), `progress` (в работе), `backlog`, `focus` (текущий фокус).

## Живой прототип внутри кейса

Прототип — React-компонент в `src/prototypes/`. В MDX:

```mdx
import EplDriverStates from '@/prototypes/EplDriverStates';

<Prototype title="Состояния водителя: попробуй сам" note="Данные демонстрационные">
  <EplDriverStates client:visible />
</Prototype>
```

Правила прототипа: все состояния из кейса (пусто, загрузка, ошибка, успех), реальные микротексты из макетов, работает с клавиатуры, уважает reduced motion. Figma-прототип — через `<FigmaEmbed url="…" />`.

## Визуалы: только реальные экраны + интерактив

Стандарт: 4–8 визуалов на кейс, минимум один интерактив. **Ничего не генерируем** — ни картинки ИИ, ни «сцены кодом» вместо макетов: автор их отверг. Источники ищи сам, не проси ссылки у автора:

| Источник | Где | Как достать |
|---|---|---|
| Экспорт Notion | `C:\Users\jonik\Documents\Новая папка\…ExportBlock…` | `device_list_dir` → `device_stage_files` (не глубже 7 уровней) |
| Figma ERP «UI-2026» | `raqehl5sQmSlnRl8GqqMPI` | `get_metadata` без nodeId — список страниц |
| Figma «TradeTaxi-v-2» | `tLlMiWWd4gHuX7gbNw7KCV`, страницы «Портфолио · База Такси», ревью 13.10.2026 | то же |
| Figma «Noboring DS 3.0» | `kL8g8C54aR6cEHkZNcE6v3` | страницы компонентов и гайдов |
| Код НФ (токены, контракты таблиц) | `C:\NF` | для прототипов НФ |

Конвейер картинки:
1. `get_screenshot` с `enableBase64Response: true`, `maxDimension: 2000–2400` — PNG сохраняется в `tool-results/mcp-Figma-blob-*.png` (прямые URL Figma из облака заблокированы).
2. `sharp` → `public/images/<slug>/<осмысленное-имя>.webp`, quality 86–92. Не апскейль: 1x-рендер оставляй в родном размере.
3. Обложка карточки — композиция из реальных экранов (`cover.webp`), без выдуманных данных.
4. Не берём кадры с заглушками дизайн-системы («Description», «tag-text») и обрезанные композиции.

Интерактив — `src/prototypes/<Case>Prototype.tsx` в `<Prototype>` с `client:visible`: повторяет реальный флоу из Figma, микротексты дословно из макетов, токены продукта (для НФ — `nf-table.css`), все состояния, клавиатура. Подпись — «Реконструкция по макетам».

## Картинки: правила подписи

- Если файла нет, `Figure` показывает заглушку с именем — сборка не падает, но перед коммитом проверь: `grep` путей из MDX против `public/`.
- `alt` описывает, что на картинке и зачем; `caption` — вывод, жирным первые слова.
- Если на экране данные — «данные демонстрационные».

## Микротексты в кейсе

- Глаголы и цифры: «сократили с месяца до 2 дней», не «значительно улучшили».
- «Я» — то, что делал сам; «мы» — команда. Роль в `Meta` разграничивает вклад.
- Без канцелярита: не «осуществлялась проверка», а «проверили».
- Оценки и наблюдения помечай: «моя оценка по наблюдениям, без замера».
